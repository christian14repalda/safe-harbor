# Safe Harbor

A gender-responsive website about violence against women and their children (VAWC) in the Philippines.
Made for the Gender and Society midterm project. Plain HTML, CSS and JavaScript. No backend, no database.

## How to open it

1. Unzip the folder.
2. Double-click `index.html`. It opens in your browser.

## Folder structure

```
safe-harbor/
├── index.html              Home
├── understanding.html      Understanding VAWC (forms of abuse, myths and facts)
├── warning-signs.html      Warning Signs (private checklist, nothing is saved)
├── legal-protection.html   Your Legal Protection (RA 9262, BPO / TPO / PPO tabs)
├── get-help.html           Where to Get Help (directory with filters, helping a friend)
├── statistics.html         Statistics (bar charts)
├── sources.html            Sources (numbered references)
├── css/style.css           All styling
├── js/main.js              Leave button, menu, tabs, filters, checklist
├── images/favicon.svg      Browser tab icon
└── README.md
```

## Features that satisfy the project requirements

- One central issue: VAWC
- Responsive: works on phones and desktops
- Interactive: warning-signs checklist, protection-order tabs, help directory filters, myth and fact cards
- Original design: lighthouse and harbor theme
- Statistics, laws and claims, each with a numbered reference that links to the Sources page

## Safety features (keep these when you edit)

- Red "Leave this site" button on every page, and Esc pressed twice also leaves
- No forms that collect information, no accounts, no tracking
- No graphic images

## Publishing the website (GitHub Pages, free)

1. Create a free account at github.com (one member does this for the group).
2. Click **New repository**. Name it `safe-harbor`, set it to **Public**, and click **Create repository**.
3. Click **uploading an existing file**. Drag in `index.html` and the other six `.html` files, then the `css`, `js` and `images` folders. Click **Commit changes**.
4. Go to **Settings > Pages**. Under **Branch**, choose `main` and `/ (root)`, then click **Save**.
5. Wait 1 to 2 minutes and refresh. The site link appears at the top of that page. It looks like `https://YOUR-USERNAME.github.io/safe-harbor/`.
6. Submit two links to the instructor: the repository link (the code) and the github.io link (the website).
